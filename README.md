# OAIW26-OKE-CLASS
Lab code for Oracle AI World 2026 training session OUT1013, Deploy and Optimize with OKE. Kubernetes manifests, helper scripts and lab notes to create OKE clusters with managed and virtual nodes, access them from Cloud Shell and a laptop, deploy the Guestbook app, pull images from OCIR, use Block Volume PVCs and autoscale pods and nodes.
